Tolong perbaiki tata letak UI (layout) pada index.html sesuai poin berikut:

1. Perbaiki Header & Profil Box (Pojok Kanan Atas):
   - Perlebar area container header bagian atas agar memiliki ruang kosong yang lebih lapang.
   - Pindahkan elemen Profil User (Nama, Badge Role, dan Tombol Logout) tepat ke pojok kanan atas (absolute/flex alignment).
   - Pastikan Profil Box tidak menabrak atau menumpuk teks judul "THE ELEVATE GAZETTE" maupun garis pembatas header.

2. Sistem Tab Menu (Memisah Panel/Slide):
   - Jangan tampilkan semua panel (seperti Admin Panel, Stats, dll) secara bertumpuk dalam satu halaman utama.
   - Buatlah sistem Tab Navigation horizontal di bawah header dengan pilihan tab (contoh: Main View, Admin Panel, Stats, dll).
   - Gunakan logika JavaScript (show/hide class) agar hanya panel dari Tab yang aktif saja yang muncul, sedangkan panel lainnya tersembunyi.
   - Tombol Tab "Admin Panel" hanya boleh terlihat/aktif jika user yang login memiliki role "ADMIN".

3. Pertahankan gaya visual tema koran vintage (The Elevate Gazette) yang sudah ada.
