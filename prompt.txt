Tolong perbarui fitur Login dan Register pada project ini dengan menggunakan Firebase SDK v12 CDN dan ketentuan sebagai berikut:

1. Form Register:
   - Input yang diminta HANYA:
     * Nama Lengkap
     * Password
     * Konfirmasi Password
   - Validasi: Jika "Password" dan "Konfirmasi Password" tidak cocok, tampilkan pesan error dan batalkan proses register.
   - Otomatis buat format email dummy di background dari Nama Lengkap, contoh: `nama_lengkap@elevate.local` (ubah ke huruf kecil dan ganti spasi dengan `_`).
   - Simpan dokumen ke Firestore koleksi `users`:
     {
       uid: user.uid,
       nama_lengkap: nama,
       generated_email: emailDummy,
       role: "NON ELEVATE", // Default akun baru
       createdAt: serverTimestamp()
     }

2. Form Login:
   - Input yang diminta HANYA: Nama Lengkap dan Password.
   - Logika Login: Format Nama Lengkap inputan menjadi email dummy (`nama_lengkap@elevate.local`), lalu panggil `signInWithEmailAndPassword(auth, generated_email, password)`.
